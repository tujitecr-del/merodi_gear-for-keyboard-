タイトル：merodi_gear（メロディーギア）


- 操作方法 -

・スマホ　タッチパネル　PCマウス(trackpad）

　・ゲームパッド対応版(for game pad)

　・PCキーボード対応版(for keyboard)


戦闘時の操作方法：

PCキーボードは
「←A」「→S」「↑W」「↓Z」
「EN i」「バリア o」「近 k」「遠 l」


MP3や自作曲からロボットを生成して戦う、2D横格闘ゲームです。
ENを回復しつつ、ENを消費してジャンプや攻撃を行ってください。
リアルタイム対人戦闘ではなく、放置対戦用に放置されている
電脳搭載機体を掲示板から選び戦うシステムです。

-----
1.「index」

2.「あなたの基地」（3か4か8か9を選ぶ）

　　3.「アバター編集」

　  4.「機体生成・改造・搭乗」
 
　　　 5.「格納庫」
 
　　　　　6.自機生成50体までの保管

　　　　　　7.「管理」「搭乗する」

           　8.「管理」：
　　　　　　　　「音楽から機体生成」
　　　　　　　　　姿、曲名、色、
　　　　　　　　　機体サイズ、
         　　　　  攻撃力、防御力、速さ　
　　　     
             9.「機体改造」
                電脳レベルの値を、
                機体サイズ、攻撃力、防御力、
                速さに割り振れる。

　　　　　 10.「放置機体と戦闘」
　　　　　  　自機をフィールドに待機させて、
               他人と戦わせるモード
　　　　　（放置自機が勝利、電脳レベル＋4）
　　　　　（放置自機が敗北、電脳レベル＋2）
　　　　　　１時間の放置後に再参戦可能。　

　　　　　11.「あなたの基地へ戻る」


12.「BGM作曲」
　（.merogefail独自拡張子）　
　　作曲ソフト　　試聴
   「ロボット格納庫」で使用楽曲を
　　選べば、放置対戦時に相手のBGM
　　として聞かせる事ができます。

13.「誰かの放置機体と対戦」
      自機を操作して、誰かの作ったCPUと戦うモード。
　　  1試合5分。
      100人まで表示、新しいが来たら順に下に下がる。

機体引継ぎ：

このゲームはサーバーを使わず、
あなた自身でデータを保管するスタイルです。

機種変更やブラウザ変更の際は、
以下の手順で愛機を引き継げます。

保管: 「機体データをコピー」ボタンを押し、
　　　表示された文字列をメールやメモ帳に
　　　貼り付けて保存してください。

復元: 新しい端末でこのページを開き、
　　　保存した文字列を下の箱に貼り付けて
　　　「機体データを復元」を押してください。

-----
.melogefileについて：
　
このゲームでのみ使用できる、JSON形式の
BGMファイルの拡張子です。

ゲーム内のシステムから自身で作曲することも可能。
機体詳細画面で、
放置戦闘時に相手にBGMとして聞かせることも可能。

戦闘後、戦った相手のBGMを入手できます。
入手した楽曲から機体生成も可能。
貰ったBGMは、放置する自機のBGMとしても使用可能。
