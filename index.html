🎵 merodi_gear（メロディーギア）

MP3や自作曲からロボットを生成して戦う、2D横格闘ゲームです。
ENを回復しつつ、ENを消費してジャンプや攻撃を行ってください。
リアルタイム対人戦闘ではなく、放置対戦用に放置されている電脳搭載機体を掲示板から選び戦うシステムです。

🎮 操作方法

・スマホ：タッチパネル / PCマウス (trackpad)
・ゲームパッド対応版 (for gamepad)
・PCキーボード対応版 (for keyboard)

戦闘時のキーボード操作：
* 移動：← A・→ S・↑ W・↓ Z
* アクション：EN i / バリア o / 近接 k / 遠距離 l

🗺️ メニュー・機能の流れ

  1. 「index（トップ画面）」
  2. 「あなたの基地」
    • アバター編集
    • 機体生成・改造・搭乗
      • 格納庫（自機50体まで保管）
        • 管理：「音楽から機体生成」「機体改造」
        • 放置機体と戦闘（勝利でLv+4、敗北でLv+2）
  3. 「BGM作曲」（.merogefile 拡張子）
    作曲・試聴機能。ロボット格納庫で選べば放置戦闘時の相手のBGMになります。
  4. 「誰かの放置機体と対戦」
    自機を操作してCPUと戦うモード（1試合5分）。

⚔️ バトル基本ルール

  • 手動操作：ENチャージ / バリア / 遠距離 / 近距離
  • 各ステータス上限：電脳レベル 100 / 攻撃力 999 / 防御力 999 / 速さ 999

💾 機体データの引き継ぎ

サーバーを使わず、ご自身でデータを保管するスタイルです。
* 保管：「機体データをコピー」で文字列を保存。
* 復元：新しい端末の入力欄に貼り付けて「機体データを復元」。

🎶 .merogefile について

このゲーム専用のJSON形式BGMファイル拡張子です。
自作できるほか、戦闘後に勝った相手のBGMを入手して機体生成や自機のBGMに流用可能です。
